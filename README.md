# EMI-calculator
The EMI Calculator is a user-friendly web tool built using HTML, Bootstrap, and JavaScript that allows users to calculate their monthly loan payments instantly.It is designed with a clean and responsive layout using Bootstrap, making it accessible on all devices including mobiles and tablets.

🔧 Features:

Input Fields:

Loan Amount – Enter the principal amount.

Interest Rate – Input the annual interest rate (in %).

Loan Tenure – Select the duration in months or years.

Output:

Monthly EMI – Displays the calculated EMI.

Total Interest – Shows the total interest payable over the loan term.

Total Payment – Displays the total amount payable (Principal + Interest).

Interactive Elements:

Real-time calculation using JavaScript as the user adjusts values.

Bootstrap-styled form elements and result cards for a professional look.

Responsive design that adapts to various screen sizes.

This calculator helps users plan their loans efficiently by providing instant financial estimates without requiring any backend processing.
